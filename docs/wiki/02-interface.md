# 02 认识窗口

默认仍是五个分区（编号与图中一致）。**面板标题可以拖到别的分区**，像专业 CAD 的停靠窗口；不能把面板关干净，也不能弹出独立小窗。拖乱了用 **视图 → 复位布局**。

![主窗口五个分区：功能区、数据集与节点、工作区、属性、日志](../assets/wiki/interface-overview.png)

## 1 顶部：功能区（Ribbon）

一排**标签**，点标签下面才出现按钮。刚打开软件时选中**主页**。常驻的是文件 / **主页 / 数据 / 视图 / 绘图**。点中间不同窗口时，右侧会多出带顶栏色条的**上下文标签**（和专业版 Qt 软件一样，不是单独的圆角色块）：

| 标签 | 何时出现 | 你在这里做什么 |
|------|----------|----------------|
| **文件** | 一直在 | 新建 / 打开 / 保存 / 另存为 / 退出工程 |
| **主页** | 一直在 | 打开/保存；撤销、重做（只针对**工作流画布**的增删连线，不是改表格格子）；**复制 / 粘贴 / 删除 / 全选**（焦点在表格改单元格，焦点在工作流改节点，焦点在绘图时复制把图拷到剪贴板）；创建里的**添加数据**；Ping；**配置**里的设置、关于；**帮助**菜单（手册/教程/常见问题） |
| **数据** | 一直在 | **添加数据**、移除、重命名、导出。清洗按钮不在这里 |
| **视图** | 一直在 | 把某个停靠面板提到前面（表格/工作流/绘图/数据集/节点/属性/日志）；**复位布局** |
| **绘图** | 一直在 | 新建折线 / 散点 / 柱状 / 直方 / 箱线 / 子图 |
| **操作** | 点了中间**表格** | 清洗、过滤、统计（对**当前选中的那张表**立刻改，或生成新表） |
| **工作流视图** | 点了中间**工作流** | 放大 / 缩小 / 适应画布 |
| **工作流** | 点了中间**工作流** | 运行 / 停止积木图 |
| **图表** | 点了中间**绘图** | 标注，导出 PNG/SVG/PDF |

标签行右侧的箭头可以把功能区收成只剩标签。右上角 **EN / 中文** 切换界面语言（按钮大小不变）。也可以 **主页 → 设置**。窗口最小化、最大化、关闭用最右侧系统按钮。

标题栏最左侧是软件图标。中间空白处可拖动窗口。

## 2 左侧

两个页：**数据集** 和 **节点**。

- **数据集**：已经加载进内存的表。点一行，中间「表格」就显示它。空的时候会提示用「数据 → 添加数据」。
- **节点**：工作流积木清单。拖到中间「工作流」页。

## 3 中间工作区

三个页签：

| 页签 | 作用 |
|------|------|
| **表格** | 浏览当前数据集，可改单元格 |
| **工作流** | 拖节点、连线 |
| **绘图** | 看图、缩放、改样式 |

一次可以只看一个页签，也可以把「表格 / 工作流 / 绘图」拖成左右分栏。导入数据后先看「表格」；画图后会自动切到「绘图」。

## 4 右侧：属性

取决于你点了什么：

- 点了数据集：名称、行列数、每列类型。
- 点了工作流节点：该节点的参数（例如查询表达式）。
- 点了图：标题、轴标签、颜色、线宽、网格、图例。
- 什么都没选：提示「未选择对象」。

## 5 底部：日志

英文/中文夹杂的运行记录。成功导入、筛选删了几行、sidecar 崩溃，都会写在这里。测试时**出问题先看最后几行**。

## 三个容易混的词

| 词 | 白话 |
|----|------|
| 数据集 | 已经进软件内存的一张表，左边列表里的一项 |
| 工程 | 整个工作现场（多张表 + 工作流 + 图），存成 `.dwproj` |
| sidecar | 后台 Python 进程，真正算 pandas 的地方。界面只负责显示 |
