# 01 安装与启动

目标：让窗口出现，底部状态栏显示 **就绪**。做不到后面都没法测。

用安装包即可。**不必安装 Python，也不必使用命令行。**

## 电脑需要什么

| 必须有 | 说明 |
|--------|------|
| Windows 10/11（64 位） | 当前支持的系统 |
| 安装包 | 文件名类似 `DataWorkbench-Setup-*.exe` |

示例表不用另外准备：第一次打开软件后，会出现在 `文档\DataWorkbench\wiki-demo.csv`。

## 安装

1. 双击安装程序。
2. 若弹出 Windows 帐户控制，点「是」。按向导「下一步」：同意许可。默认目录是 `C:\Program Files\DataWorkbench`（可改到自己的用户目录）。
3. 安装结束可勾选立即运行，或从桌面 / 开始菜单打开 **DataWorkbench**。
4. 看窗口**底部状态栏**：左边圆点变绿并写 **就绪**，才算成功。日志会写「计算引擎已就绪」。
5. 打开 **主页 → 帮助 → 用户手册**，以后对照都在软件里面，不用上网。

不需要再装 Python，也不用在命令行执行任何命令。

![启动后主窗口：底部状态栏为就绪，日志写「计算引擎已就绪」](../assets/wiki/01-ready.png)

## 启动自检（30 秒）

- [ ] 窗口可见（标题栏有软件图标，顶部有「文件 / 主页 / 数据 / 视图 / 绘图 …」）。
- [ ] 底部状态栏为 **就绪**，没有一直停在「正在启动」。
- [ ] **主页 → 帮助** 能打开本手册。
- [ ] 资源管理器里能看到 `文档\DataWorkbench\wiki-demo.csv`。若没有，从帮助目录继续，或把日志发给开发者。

失败先看 [10 常见问题](./10-faq.md)。通过后去做 [08 十五分钟跟做](./08-tutorial.md)，并先浏览 [11 怎样测软件](./11-how-to-test.md)。
