# DataWorkbench 使用手册

这份手册面向**第一次打开软件的人**。不要求你会 Python、pandas，也不要求你做过数据分析。按页面顺序点一遍，就能完成：导入表格 → 清洗几行 → 画一张图 → 保存工程。各页配有真实窗口截图，对照图上的编号找按钮即可。

软件默认界面是中文。窗口右上角可切到 English。下文按钮名称按中文写。

## 软件能做什么

把表格（Excel / CSV）放进软件后，你可以：

1. 像 Excel 一样滚动浏览、改格子。
2. 用顶部按钮做常见清洗：删空行、去重复、按条件留行、排序、出统计表。
3. 把同样的步骤连成**工作流**（积木图），下次换一份表再点「运行」。
4. 画折线 / 散点 / 柱状 / 直方 / 箱线，改标题和颜色，导出 PNG、SVG 或 PDF 插到 Word。
5. 把当前状态存成 `.dwproj` 工程，关掉再打开还在。

## 它不做什么

- 没有 AI 对话助手。
- 不能打开旧版 Qt 软件的 `.dapro` 工程。
- 图表上不能拖箭头、文本框（改样式请用右侧属性面板）。
