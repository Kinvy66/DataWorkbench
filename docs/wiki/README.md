# DataWorkbench 使用手册

各页配有窗口截图，对照图上的位置找按钮。软件默认界面是中文。窗口右上角可切到 English。

**测试时不必把每一页都读完。** 先按下面「必做」走主路径，02–07 当词典：某个按钮看不懂、或清单某条要对期望时再打开对应页。10 只在卡住时查。

## 测试时怎么用这本手册

手册写的是：**软件应有的正确表现。**

安装后对照本手册操作。不要只看弹窗是否显示成功，还要看表格、图、导出的文件，以及关掉再打开是否还在。

手册说 A、软件却是 B，就记下来，写成缺陷。记完继续测后面的步骤，不要停下来等修改。

观察方法和记录格式：[11 怎样测软件](./11-how-to-test.md)、[12 怎样写缺陷单](./12-bug-report.md)。

## 软件能做什么

把表格（Excel / CSV）放进软件后，你可以：

1. 像 Excel 一样滚动浏览、改格子。
2. 用顶部按钮做常见清洗：删空行、去重复、按条件留行、排序、出统计表。
3. 把同样的步骤连成**工作流**（积木图），下次换一份表再点「运行」。
4. 画折线 / 散点 / 柱状 / 直方 / 箱线，改标题和颜色，导出 PNG、SVG 或 PDF。
5. 把当前状态存成 `.dwproj` 工程，关掉再打开还在。

## 它不做什么

- 没有 AI 对话助手。
- 不能打开旧版 Qt 软件的 `.dapro` 工程。
- 图表上不能拖箭头、文本框（改样式请用右侧属性面板）。

## 示例表在哪里

第一次启动软件后，会把示例表复制到本机：

`文档\DataWorkbench\wiki-demo.csv`

（英文 Windows 上是 `Documents\DataWorkbench\wiki-demo.csv`。）

这张表有 **11 行数据**，列是 `name,age,city,score`。里面有空格子、一行完全重复的 Alice。跟做和测试请**一直用这一份**，不要随手换别的表，否则对不上手册里的人名。

## 核对时注意

1. **弹窗说成功 ≠ 功能对了。** 还要看表格、看图、看导出的文件。
2. **和手册不符就记，不要猜「可能是我点错了」就放过。** 按手册再做一遍，两遍一样就可以写单。
3. **主流程要走完。** 即使某一步不对，后面的导入、画图、工作流、保存仍要试完。
