# DataWorkbench 使用手册（练习课）

这份手册面向**第一次打开软件、也第一次做软件测试**的人。不要求你会编程，也不要求你做过数据分析。

请按页面顺序看。各页配有窗口截图，对照图上的位置找按钮即可。软件默认界面是中文。

## 你这次要做什么

别人发给你的是一份**安装包**。装好后打开软件，对照本手册操作。

手册写的是：**合格的软件应该怎样表现。**

你的任务不是把每一步都点到「弹窗说成功」就结束，而是：

1. 按手册做。
2. 看软件**实际**做了什么（表格、图、导出的文件、关掉再开）。
3. 如果手册说 A、软件却是 B，**记下来**。这就是一次有效的测试。
4. 不要停下来等开发改好。记完继续下一步，把主流程走完。

建议你至少找出 **5 处**「手册和软件不一致」。找到得越多越好。找到问题是成绩，不是你操作错了。

怎样观察、怎样写记录：请先读 [11 怎样测软件](./11-how-to-test.md) 和 [12 怎样写缺陷单](./12-bug-report.md)。

## 软件能做什么

把表格（Excel / CSV）放进软件后，你可以：

1. 像 Excel 一样滚动浏览、改格子。
2. 用顶部按钮做常见清洗：删空行、去重复、按条件留行、排序、出统计表。
3. 把同样的步骤连成**工作流**（积木图），下次换一份表再点「运行」。
4. 画折线 / 散点 / 柱状 / 直方 / 箱线，改标题和颜色，导出 PNG、SVG 或 PDF。
5. 把当前状态存成 `.dwproj` 工程，关掉再打开还在。

## 它不做什么

- 没有 AI 对话助手。
- 不能打开旧版 Qt 软件的 `.dapro` 工程。
- 图表上不能拖箭头、文本框（改样式请用右侧属性面板）。

## 示例表在哪里

第一次启动软件后，会把练习表复制到本机：

`文档\DataWorkbench\wiki-demo.csv`

（英文 Windows 上是 `Documents\DataWorkbench\wiki-demo.csv`。）

这张表有 **11 行数据**，列是 `name,age,city,score`。里面有空格子、一行完全重复的 Alice。跟做和测试请**一直用这一份**，不要随手换别的表，否则对不上手册里的人名。

## 三句口诀

1. **弹窗说成功 ≠ 功能对了。** 还要看表格、看图、看导出的文件。
2. **和手册不符就记，不要猜「可能是我点错了」就放过。** 按手册再做一遍，两遍一样就可以写单。
3. **走完整条路。** 即使某一步不对，后面的导入、画图、工作流、保存仍要试完。
