# 10 常见问题

先看窗口**底部日志最后几行**，再对照本页。

## 启动

### 浏览器里打开了 localhost，提示「桌面桥接未加载」

软件必须在 **Electron 窗口**里用。`pnpm dev` 会自己弹出窗口。关掉浏览器标签，回到那个桌面窗口。

### 窗口出来了，日志没有「Sidecar 已就绪」

后台 Python 没起来。检查：

1. **安装包 / 便携目录**：应已内嵌 Python。把底部日志里 `Starting sidecar:` 那一行发给开发者。
2. **开发模式**：本机是否 **Python 3.11 或 3.12**（`py -3.12 --version`），以及是否安装了 sidecar 依赖：`py -3.12 -m pip install -r python/requirements.txt`。
3. 可用 `$env:DW_PYTHON = "C:\路径\python.exe"` 覆盖解释器后再启动。

### Ping 失败

Sidecar 没就绪时 Ping 会失败。等就绪日志出现再点。失败文案是「host.hello 失败：…」，把后面原因发给开发者。

### `spawn electron.exe ENOENT`（只有开发模式）

Electron 二进制没下下来。按仓库根目录 [README.md](../../README.md) 里「electron.exe ENOENT」一节处理。普通用户请改用安装包 `DataWorkbench-Setup-*.exe`。

### 安装时提示「不能打开要写入的文件」（uninstallerIcon.ico / Program Files）

默认目录是 `C:\Program Files\DataWorkbench`，写入需要管理员权限。点 **中止**，不要点忽略。

- 用新安装包：双击后应先弹出 Windows 帐户控制，点「是」再继续。
- 若 UAC 被取消或被策略拦截：右键安装包 **以管理员身份运行**。
- 也可以点「上一步」，把目录改成例如 `%LOCALAPPDATA%\Programs\DataWorkbench`。

## 数据

### 添加数据后表格是空的

1. 左边是否**点中了**刚导入的那一项。
2. 中间是否切到 **表格**（不是工作流/绘图）。
3. 空表提示是「选择一个数据集以浏览表格」——说明没选中。

### 导入 pickle / `.pkl` 不行

故意关闭的，提示「已禁用 pickle 导入」。请用 csv / xlsx / parquet。

### 改格子一按 Enter 又变回去

这一列是数字，你填了文字（或反过来）。按列类型填，或先导出再在 Excel 里改类型后重新导入。

### 清洗按钮在哪？「数据」标签里没有

在 **操作** 标签。数据标签只有添加 / 移除 / 重命名 / 导出。

### 找不到「替换值」「阈值筛选」按钮

功能区没有这两项，请到左侧 **节点** 拖 `Replace Values`、`Threshold Filter`。说明见 [05 工作流](./05-workflow.md)。

## 操作与筛选

### 条件筛选报错

常见原因：

- 列名写错，或大小写不对（`Age` 和 `age` 不是同一列）。
- 文字两边没用英文单引号：应写 `city == 'Beijing'`。
- 中文引号、中文逗号。

### 列数据过滤把不该删的删了

最小/最大填 **0** 表示数字零，不是「不限制」。某一侧不限制请关掉对应开关。

### 数值计算没反应 / 失败

必须写成赋值，例如 `s2 = score + 1`。只写 `score + 1` 会被拒绝。

### 统计表把原表「覆盖」了？

没有。**数据描述**和**数据透视表**会在左边**新加一条**。点原来的名字才能回到原表。

## 工作流

### Data Source 跑完没有表

`Data Source` **不读磁盘文件**。必须先 **数据 → 添加数据**，再把属性里的 dataset_name 写成左边列表里的名字。

### 运行完左边没有新表

结果要接到 `Output to DataManager`，并给一个新的 data_name，然后点 **工作流 → 运行**。只连 Query 不发布，内存里算完也不会出现在列表。

### 打开工程后画布是空的、节点丢了

工程损坏或保存不完整。正常文件应先恢复表和逻辑再摆位置。不要用记事本改 `.dwproj`。用备份或另存为的那份再开。仍失败把文件发给开发者，并看日志。

### 正在运行时拖不动

提示「工作流正在运行」。等结束，或点 **停止**。

### 撤销改不回表格里改过的格子

Ctrl+Z 只撤销**工作流画布**（节点、连线），不撤销单元格。格子请再改回去，或重新导入 / 打开工程。

## 图表

### 点了折线但中间还是表格

切到中间的 **绘图** 页签。

### 图是空白的

- Y 列或直方列必须是数字（不要选 `name`）。
- 空值太多会提示「没有足够的数值点」。先填充或删除缺失值。
- 试 **复位视图**。

### 图上不能拖箭头、文本框

可以 **图表 → 文本 / 箭头** 后在图上**点击放置**，再用右侧属性改文字。不能像 PowerPoint 那样拖着标注到处飞。

## 工程与崩溃

### 关掉软件后再开，表没了

数据只在内存里，除非当时 **文件 → 保存** 成了 `.dwproj`。源 CSV 还在磁盘上，可再导入。

### 日志写 sidecar 崩溃、数据丢失

后台 Python 挂了，界面会自动重启一次计算进程，但**没保存的表会丢**。打开已保存的工程恢复。文案：「Sidecar 已重启。内存中的数据已丢失，请打开已保存的工程恢复。」

### 提示 sidecar 无法再重启

连挂两次后可能停。关掉整个软件再开。先保证已保存。

### 打不开别人给的 `.dapro`

那是另一套 Qt 软件的工程。本软件只认 **`.dwproj`**。

### 保存时杀进程，工程坏了吗？

软件先写临时文件再替换。强制结束时，**原来那份** `.dwproj` 应仍能打开；未完成的保存不会当成功。若两份都不能开，用备份。

## 还是不行

把这些一并记下：

1. 用的是安装包、`win-unpacked` 里的 exe，还是 `pnpm dev`。
2. 安装包用户可跳过 Python 版本；开发模式记下 `py -3.12 --version`。
3. 日志最后 20 行（可复制）。
4. 你点了哪个标签的哪个按钮。

开发约定与架构不在本手册，见 [docs/dev_plan](../dev_plan/README.md)。
