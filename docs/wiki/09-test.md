# 09 手工测试清单

示例表一律用 `文档\DataWorkbench\wiki-demo.csv`。

每一条写的是**软件应有的表现**（和手册一致）。

- 相符 → 打钩，表示这条通过。
- 不符 → 打叉，并写成 [缺陷单](./12-bug-report.md)。不要把未通过的改成打钩。

开始前：[01](./01-install.md) 启动自检已过。观察方法见 [11](./11-how-to-test.md)。

建议先完整做完 [08](./08-tutorial.md)，再按本页补漏。A–F 都要做到；G 为选做。

## A. 窗口与语言

- [ ] 窗口标题区有软件图标，顶部能看到 **文件 / 主页 / 数据 / 视图 / 绘图**。点中间表格后出现 **操作**；点工作流后出现 **工作流视图** 和 **工作流**；点绘图后出现 **图表**。
- [ ] 底部状态栏显示 **就绪**，日志出现「计算引擎已就绪」。
- [ ] **主页 → 设置**：能把界面改成 English 再改回中文。**关掉软件再开**，语言应还是你最后选的那种。功能区右上角 **EN / 中文** 同样生效（同样要试一次重启）。**打开日志文件夹** 能看到 `main.log`。
- [ ] **主页 → 关于**：显示软件名、版本号、版权。
- [ ] **主页 → 帮助**：出现手册 / 教程 / 常见问题 / 怎样测软件 / 怎样写缺陷单；点一项会打开帮助窗口（不要跳到网页）。
- [ ] 能把左侧「节点」标签拖到中间或右侧；**视图 → 复位布局** 回到默认分区。
- [ ] **视图 → 表格区域** 会把中间表格提到前面并出现 **操作**；**视图 → 工作流区域** 会切到工作流。

## B. 数据导入与表格

- [ ] **数据 → 添加数据** 打开 `wiki-demo.csv`，左边有数据集，表格有 `name,age,city,score`。
- [ ] 日志类似「已导入 …（**11** × 4）」。请同时看右侧属性的行数，并大致数一下表里有没有 11 行（含表底那行重复的 Alice）。三处应一致。
- [ ] 滚到表格底部再滚回顶部，不卡死、不闪退。
- [ ] 改一个单元格（例如 Alice 的 score）再改回去，Enter 能确认。
- [ ] 点一个单元格，**主页 → 复制**，再点另一格 **粘贴**。**删除**把格子变空。
- [ ] **数据 → 重命名数据** 改名后再改回来，日志「数据集已重命名」。
- [ ] **数据 → 导出** 存一份 csv。用**记事本**打开：第一行应是列名 `name,age,city,score`，第二行才是 Alice。用 Excel 打开也应看见表头。
- [ ] **数据 → 移除数据** 确认后列表空了；磁盘上的 `wiki-demo.csv` 还在。
- [ ] 再导入一次。

有 Excel 时加测：随便存一个最少两列的 `.xlsx`，同样能出现在列表里。

## C. 操作按钮（清洗立刻改当前表）

先重新导入一份干净的 `wiki-demo.csv`（可先新建工程不保存）。点中间 **表格**，确认顶部出现 **操作**。

- [ ] **删除缺失值**（默认）：表里再也找不到 Bob、Dave；日志写的删除行数和少掉的行一致。
- [ ] 重新导入后 **填充缺失值**（固定值 `0`，列选 age 和 score）：空格子变成 0，行还在。这一条请认真看格子，它和「删除」不是同一件事。
- [ ] **删除重复值**（保留第一次）：滚到表底，两行完全相同的 Alice 变成一行。
- [ ] **条件筛选** `city == 'Beijing'`：`city` 列只剩 Beijing，不应再有 Shanghai。
- [ ] **列数据过滤**：列 `score`，最小 70、最大 90；超出区间的行消失。
- [ ] **数据排序**：按 `score` **降序**，第一行应是最高分；再试一次 **升序**，第一行应是最低分（空值按软件实际规则排即可，不闪退）。两种方向都要看第一行。
- [ ] **数值计算**：只填 `score + 1` 应失败；改成 `s2 = score + 1` 成功并多一列。
- [ ] **数据描述**：左边**多**一张 describe 表，**原表仍在**。点 describe 能看到 count / mean。
- [ ] **数据透视表**：行索引 `city`，值 `score`，聚合均值；生成新表能打开。

## D. 工作流

左边先有一张导入的表。

- [ ] 拖出 `Data Source`、`Query`、`Output to DataManager`（可再加 Start / End，不加也能跑）。
- [ ] 能连线；重复连同一对端口会提示已经连上。
- [ ] Data Source 的 dataset_name 填对；Query 填 `age > 25`；Output 的 data_name 填新名字如 `adults`。
- [ ] **工作流 → 运行**，日志「工作流已完成」，左边出现 `adults`。点开确认年龄都大于 25。
- [ ] Ctrl+Z / **主页 → 撤销** 能撤掉刚删的连线。
- [ ] Query 填乱码再运行：节点失败、日志有原因、窗口不退出。
- [ ] 运行过程中再拖节点：提示工作流正在运行。

## E. 图表

选中带数值列的数据表，不要选 describe 表。

- [ ] **绘图 → 折线**，X=`age`，Y=`score`，中间「绘图」有曲线；日志「已绘制 … 点」。
- [ ] 右侧改标题，**看图的上方**标题马上变；改轴标签、线色，图上马上变。
- [ ] **复位视图** 后能看到整条曲线。
- [ ] **散点 / 柱状 / 直方 / 箱线** 各成功一次（直方和箱线选一个数值列即可）。
- [ ] 点中间「绘图」后 **图表 → 文本**，在图上点一下出现文字；属性里能改字。
- [ ] **绘图 → 子图** 选 1×2，点左格绑折线、点右格再绑一条。
- [ ] **图表 → PNG**、**SVG**、**PDF** 各导出一份，文件能打开。
- [ ] 未绘图时点导出：提示请先绘图。
- [ ] Y 列选 `name`：报错，不画出乱图。

## F. 工程文件

- [ ] Ctrl+S 存 `test.dwproj`，日志「工程已保存」。
- [ ] **关掉软件再打开**该文件：表还在、工作流连线还在、**绘图页有曲线**（允许重算，不要求像素级一样）。
- [ ] 再点工作流 **运行** 仍能出结果。
- [ ] Ctrl+Shift+S 另存一份，两份都能开。
- [ ] Ctrl+N 新建；有未保存改动时应弹出「未保存的更改」。
- [ ] 把一个 txt 改后缀成 `.dwproj` 再打开：提示不是 DataWorkbench 工程，当前内容不被半覆盖。
