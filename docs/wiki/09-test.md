# 09 手工测试清单

给测试同学和自己验收用。不要求会写代码，也没有 Playwright 点按钮脚本。示例表一律用 `docs/wiki/samples/wiki-demo.csv`。

每条：**操作 → 期望**。打钩表示过了。失败把底部日志最后几行和按钮路径记下来。

开始前：[01](./01-install.md) 启动自检已过。

## A. 窗口与计算进程（对应「sidecar 不能把整个软件打死」）

- [ ] 窗口标题区有软件图标，顶部能看到 **文件 / 主页 / 数据 / 操作 / 工作流 / 图表**。
- [ ] 底部日志出现「Sidecar 已就绪」，且 pandas 为真。
- [ ] **主页 → Ping**，日志「host.hello 成功」。
- [ ] **不要**用浏览器打开 Vite 地址；若误开，应看到「桌面桥接未加载」，回到 Electron 窗口即可。

## B. 数据导入与表格（对应红线：csv/xlsx 导入 + 虚表滚动）

- [ ] **数据 → 添加数据** 打开 `wiki-demo.csv`，左边有数据集，表格有 `name,age,city,score`。
- [ ] 日志类似「已导入 …（行 × 列）」。
- [ ] 滚到表格底部再滚回顶部，不卡死、不闪退。
- [ ] 改一个单元格（例如 Alice 的 score）再改回去，Enter 能确认。
- [ ] **数据 → 重命名数据** 改名后再改回来，日志「数据集已重命名」。
- [ ] **数据 → 导出** 存一份 csv，用记事本或 Excel 能打开。
- [ ] **数据 → 移除数据** 确认后列表空了；磁盘上的 `wiki-demo.csv` 还在。
- [ ] 再导入一次。不要选 `.pkl`：应提示已禁用 pickle，而不是把表读进来。

有 Excel 时加测：随便存一个最少两列的 `.xlsx`，同样能出现在列表里。

## C. 操作按钮（清洗立刻改当前表）

先重新导入一份干净的 `wiki-demo.csv`（可先新建工程不保存）。

- [ ] **删除缺失值**（默认）：Bob、Dave 所在行消失；日志写删除行数。
- [ ] 重新导入后 **填充缺失值**（固定值 `0`，列选 age 和 score）：空格子变成 0，行还在。
- [ ] **删除重复值**（保留第一次）：两行完全相同的 Alice 变成一行。
- [ ] **条件筛选** `city == 'Beijing'`：只剩北京。
- [ ] **列数据过滤**：列 `score`，最小 70、最大 90；超出区间的行消失。
- [ ] **数据排序**：按 `age` 升序，空值按软件实际规则排（不闪退即可）。
- [ ] **数值计算**：只填 `score + 1` 应失败；改成 `s2 = score + 1` 成功并多一列。
- [ ] **数据描述**：左边多一张 describe 表，**原表仍在**。
- [ ] **数据透视表**：行索引 `city`，值 `score`，聚合均值；生成新表能打开。

## D. 工作流（对应红线：拖节点 → 筛选 → 输出到数据管理器）

左边先有一张导入的表。

- [ ] 拖出 `Data Source`、`Query`、`Output to DataManager`（可再加 Start / End，不加也能跑）。
- [ ] 能连线；重复连同一对端口会提示已经连上。
- [ ] Data Source 的 dataset_name 填对；Query 填 `age > 25`；Output 的 data_name 填新名字如 `adults`。
- [ ] **工作流 → 运行**，日志「工作流已完成」，左边出现 `adults`。
- [ ] Ctrl+Z / **主页 → 撤销** 能撤掉刚删的连线（不管表格格子）。
- [ ] 拖 `Delay`（几秒），运行后立刻 **停止**，日志「工作流已停止」。
- [ ] Query 填乱码再运行：节点失败、日志有原因、窗口不退出。
- [ ] 运行过程中再拖节点：提示工作流正在运行。

## E. 图表（对应红线：折线 + 改样式 + PNG/SVG）

选中带数值列的数据表，不要选 describe 表。

- [ ] **图表 → 折线**，X=`age`，Y=`score`，中间「绘图」有曲线；日志「已绘制 … 点」。
- [ ] 右侧改标题、轴标签、线色，图上马上变。
- [ ] **复位视图** 后能看到整条曲线。
- [ ] **散点 / 柱状 / 直方** 各成功一次（直方选一个数值列即可）。
- [ ] **图表 → 文本**，在图上点一下出现文字；属性里能改字。
- [ ] **图表 → PNG**、**SVG**、**PDF** 各导出一份，文件能打开。
- [ ] 未绘图时点导出：提示请先绘图。
- [ ] Y 列选 `name`：报错，不画出乱图。

## F. 工程文件（对应红线：保存/打开后拓扑和表还在）

- [ ] Ctrl+S 存 `test.dwproj`，日志「工程已保存」。
- [ ] 关掉软件再打开该文件：表、工作流连线、图（允许重算）都在。
- [ ] 再点工作流 **运行** 仍能出结果。
- [ ] Ctrl+Shift+S 另存一份，两份都能开。
- [ ] Ctrl+N 新建；有未保存改动时应弹出「未保存的更改」。
- [ ] 把一个 txt 改后缀成 `.dwproj` 再打开：提示不是 DataWorkbench 工程，当前内容不被半覆盖。

## G. Sidecar 崩溃（可选，对应红线：提示并拉起，不杀整个窗口）

仅在你愿意打断一次后台进程时做：

1. 先保存工程。
2. 打开任务管理器，结束与本软件一起出现的 `python.exe`（sidecar），**不要**结束 `DataWorkbench.exe` / `electron.exe`。
3. 日志应出现崩溃并「正在自动重启一次」，随后「Sidecar 已重启。内存中的数据已丢失…」。
4. 窗口还在。打开刚才保存的工程，表能回来。
5. 若连续搞挂两次，可能提示无法再重启，此时关软件重开即可。

## 不测什么

- 没有自动 UI 脚本，本页全是手工。
- 不测 AI 助手（本软件没有）。
- 不测打开 `.dapro`。
- 不测图表上拖箭头/文本框。
- 不测 50 万行性能（那是开发合同；日常用 wiki-demo 即可）。

全部 A–F 打钩，即可认为普通用户路径可验收。细节说明见 [03](./03-data.md)～[07](./07-project.md)，异常见 [10](./10-faq.md)。

## H. 安装包 / 便携目录（对应红线：不必先装 Python）

开发者在仓库根执行 `pnpm pack:win`。脚本结束会跑 `scripts/smoke-pack-win.ps1`：确认 NSIS 安装包存在、便携目录内嵌 `python-runtime`、**没有**打进 `.venv` / 测试目录，并且用内嵌解释器完成 `host.hello`（不读本机 `DW_PYTHON`）。

手工再确认：

- [ ] 双击 `apps/dist/DataWorkbench-Setup-*.exe` 能走完向导（Program Files 会要管理员）。
- [ ] 或解压/打开 `apps/dist/win-unpacked/DataWorkbench.exe`，日志「Sidecar 已就绪」且 pandas 为真。
- [ ] 本机即使装了另一套 Python，日志里 `Starting sidecar:` 仍指向 `python-runtime\python.exe`（除非你故意设了 `DW_PYTHON`）。
