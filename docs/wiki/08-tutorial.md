# 08 十五分钟跟做

按顺序点，不要跳。示例表：`文档\DataWorkbench\wiki-demo.csv`（第一次打开软件后自动出现；11 行数据：`name,age,city,score`，含空格子和一行完全重复的 Alice）。

开始前窗口应已打开，底部状态栏为 **就绪**。还没开起来请先看 [01 安装与启动](./01-install.md)。建议先扫一眼 [11 怎样测软件](./11-how-to-test.md)。

**跟做时请对照「期望」看表格和图，不要只看绿色弹窗。** 发现手册和软件不一致：记在纸上或 [缺陷草稿](./12-bug-report.md)，然后**继续下一步**，把十五条钟走完。

## 第 1 步：导入表（约 1 分钟）

1. 顶部 **数据 → 添加数据**。
2. 选 `文档\DataWorkbench\wiki-demo.csv`。
3. 左边出现数据集（名字多半是 `wiki-demo`）。
4. 中间 **表格** 能看到列名和前几行。
5. 日志：`已导入 wiki-demo（11 × 4）`。右侧属性里的行数也应是 11。日志、属性、你自己数的行，三者应一致。

![导入后的表格：name / age / city / score](../assets/wiki/03-table.png)

看一眼：`Bob` 的 age 是空的，`Dave` 的 score 是空的，表末尾有两行完全一样的 `Alice,28,Beijing,88`。请滚到表格最底下确认第二行 Alice 在。

## 第 2 步：删空行、去重复（约 2 分钟）

1. 确认左边仍选中刚导入的表，中间是 **表格**（顶部应出现 **操作**）。
2. **操作 → 删除缺失值** → 保持默认「任一值缺失即删」→ **应用**。

![删除缺失值对话框](../assets/wiki/04-dropna-dialog.png)

3. `Bob`（空 age）和 `Dave`（空 score）应消失。请在表里找这两个人名，不要只看「已删除几行」。日志写的删除行数应和表里少掉的行一致。
4. **操作 → 删除重复值** → 保留第一次 → **应用**。多出来的那行 Alice 应只剩一行（再滚到表底确认）。

如果点错想重来：**文件 → 新建**（不保存）再重新导入，或先 **数据 → 导出** 留一份再试别的按钮。

## 第 3 步：只留下北京、再排序（约 2 分钟）

1. **操作 → 条件筛选**，表达式填：

```text
city == 'Beijing'
```

![条件筛选填写 city == 'Beijing'](../assets/wiki/04-query-dialog.png)

2. 应用后应只剩 `city` 为 Beijing 的行。请扫一眼 `city` 列，不应再出现 Shanghai、Guangzhou。
3. **操作 → 数据排序**：列选 `score`，**降序**。第一行应是表里分数最高的人，分数应从高到低。看完第一行再往下看一眼是否真的递减。

## 第 4 步：出一张统计表（约 1 分钟）

1. **操作 → 数据描述** → 生成。
2. 左边应**多**一张名字带 `describe` 的表。点它，中间变成统计数字（count、mean 等）。
3. 原来的数据表应还在列表里。再点回原来的数据表（不要停在 describe 上），后面画图才画得到分数列。

## 第 5 步：画折线并导出（约 3 分钟）

1. 左边选中**数据表**（有 `age`、`score` 的那张，不是 describe）。
2. **绘图 → 折线**。X 列 `age`，Y 列 `score` → **绘图**。

![新建折线对话框](../assets/wiki/06-bind-dialog.png)

3. 中间切到 **绘图**，应看到曲线。
4. 右侧属性把标题改成「分数随年龄」。**请看图的上方**，标题应变，不要只看输入框里的字。

![折线图「分数随年龄」](../assets/wiki/06-chart.png)

5. 点中间 **绘图** 页，顶部出现 **图表** 后点 **图表 → PNG**，存到桌面试打开。
6. 再导出一次 **SVG**（可用浏览器打开）和 **PDF**（可用阅读器打开）。

Y 列不要选 `name`。选错会提示列不是数值。

## 第 6 步：工作流再筛一遍（约 4 分钟）

前面「操作」已经改过内存里的表。工作流要从**当前还在列表里的表**取数。

1. 左边切到 **节点**，中间切到 **工作流**。
2. 拖入 `Data Source`、`Query`、`Output to DataManager`，按顺序连线（右圆点拖到下一节点左圆点）。

![工作流：Data Source → Query → Output to DataManager](../assets/wiki/05-workflow.png)

3. 点 `Data Source`，属性 **dataset_name** 填左边数据表的名字（不是 describe 那张）。
4. 点 `Query`，表达式填：`score >= 80`
5. 点 `Output to DataManager`，**data_name** 填 `high_score`。
6. **工作流 → 运行**。
7. 日志「工作流已完成」；左边出现 `high_score`。点开看行是否都是高分。

连不上：确认中间是「工作流」页，且拖的是节点列表里的项，不是从数据集列表拖。

## 第 7 步：保存工程（约 1 分钟）

1. **文件 → 保存**（或 Ctrl+S）。

![文件菜单里的保存](../assets/wiki/07-file-menu.png)

2. 存成例如桌面上的 `wiki-demo.dwproj`。
3. 日志「工程已保存」。
4. **关掉软件，再打开**，**文件 → 打开** 选这份文件。
5. 表、工作流、**图**应还在。请点中间「绘图」看曲线是否还在，不要只看「工程已打开」。工作流可再点一次运行。

## 做完你已经会

- 把 CSV 放进软件并看见表格
- 用「操作」洗表、筛选、出统计
- 画图、改标题、导出 PNG/SVG/PDF
- 拖三个节点跑通并发布新表
- 保存 / 重开 `.dwproj`
- 用「期望 vs 实际」的方式做一次软件测试

把记下的不一致整理成 [缺陷单](./12-bug-report.md)。更细的按钮说明：[03](./03-data.md)～[07](./07-project.md)。打钩练习：[09 测试练习清单](./09-test.md)。卡住：[10 常见问题](./10-faq.md)。
