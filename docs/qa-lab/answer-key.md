# QA 训练包标准答案（仅教师）

**不要发给学员。不要放进 `docs/wiki`。**

安装包通过 `apps/resources/qa-lab.flag` 打开 `DW_QA_LAB`。自动化测试默认不设该变量，因此 pytest / vitest 仍走正确逻辑。

手册（wiki）写的是**正确期望**。下表是故意植入的、学员用眼睛和记事本就能发现的问题。没有启动失败、不能导入、不能保存、工作流无法运行、只有开发者用调试器才能看见的问题。

## 仍然正确、用来给学员成就感的路径

这些**没有**植入问题，学员按手册做应当能打钩：

- 启动到 **就绪**、打开帮助手册
- 导入 CSV 本身成功（只是行数文案撒谎）
- 填充缺失值、数值计算、透视表、列过滤等未列入上表的操作
- 工作流：Data Source → Query → Output to DataManager 能跑完并出新表
- 能画出折线，能导出 PNG / SVG / PDF（标题 bug 不影响出图）
- 工程能保存、能打开；表和工作流能回来（缺的是图）

## 阅卷建议

- 写出 B1–B10 中任意 5 条，且步骤+期望+实际清楚，即达到练习目标。
- 写到「弹窗成功但表格没变」这类**方法**，即使编号对不上，也给方法分。
- 把「工作流不能用」当成缺陷：先确认学员是否连错线；训练包里工作流应可用。
- 不要因为学员用了不同措辞（例如「去空值没用」）而判错。
